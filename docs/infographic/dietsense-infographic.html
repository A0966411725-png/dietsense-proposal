2Abstract A–F 研究故事

AAttention：全球逾 8.9 億成人肥胖（WHO 2022）；台灣男性過重＋肥胖 58.4%、女性 42.6%；成人 68% 每天至少外食一餐（國健署）
BBut：App 記錄 5.4→1.4 天／週（12 週）；漏記 18% 品項；拍照 App 每餐少算 250–345 kcal；珍奶低估達 76%
CCure：DietSense 對話式熱量攝取 Domain AI Agent，用一句中文完成記錄
DDevelopment：LLM Planner＋台灣優先 RAG＋份量表＋Mifflin-St Jeor＋區間＋安全守門
EExperiments：500 筆台式料理標註集；純 LLM、手動查詢兩種基準；20 人 × 7 天
FFindings（Expected）：±20% 命中率優於純 LLM、記錄時間更短、SUS > 70

35 個核心 ＋ 3 個取捨

  1. C1 問題：記錄太累 → 沒人持續記錄
  2. C2 缺口：好用的不準，準的不好用
  3. C3 解法：LLM 只理解語言，數字交給資料庫與公式
  4. C4 誠實：區間 low / point / high＋來源
  5. C5 安全：不助長過度節食
T1 準確 vs. 負擔 → 最多追問 1 次，其餘加寬區間
T2 資料錨定 vs. LLM 直估 → 錨定為主，純 LLM 必測
T3 個人化 vs. 安全可解釋 → Mifflin-St Jeor＋固定安全下限，不做醫療個人化

5Algorithm 1（節錄）與 10 個細節

01 q ← normalize(Q);  intent, ents ← classify_and_extract(q)
06 C ← retrieve(e, [TW_FCD, TW_DISH_VEC, USDA_FDC]); (m,c) ← rank(C)
08 if c < τ and not e.asked: ask(clarify(e)); e.asked ← true
11 k ← grams · m.kcal_per_100g / 100
12 w ← w0 + α(1−c) + β·vagueness(e);  log (k(1−w), k, k(1+w))
14 S ← compute_daily_state(D, P)     ▷ 總量・巨量營養素・TDEE
15 risk ← safety_check(D, H7, P, S)   ▷ 完整日 / 7 日平均
  1. 意圖四分類，不明就回問
  2. 實體＝食物＋份量＋修飾＋餐別
  3. 檢索順序：TW → 台式庫 → USDA
  4. 信心門檻 τ = 0.80（W6 校準）
  5. 區間：w0 .10、α .50、β .15
  1. 份量表依食物類別換算克數
  2. TDEE = BMR × 1.2–1.9
  3. 國健署指南：醣 50–60／蛋 10–20／脂 20–30%
  4. <1,200 kcal 以完整日／7 日判斷
  5. 評估：MAE、MAPE、coverage、SUS
